## Changes since 1.3.0

One line per change, be concise and explicit. Document only external changes
in behavior visible for the end-users of the tooling.

* New Italian surface syntax (`--language=it`, `.catala_it` files), with a
  localised standard library (`Stdlib_it`), Pygments and Vim syntax
  highlighting, and Italian formatting of values (`1.234,56 €`, `vero`/`falso`,
  `[2 anni, 3 mesi]`).
