Module Clerk_backend.Backend_paths

/

Backend path/command helpers. Windows behaviour is testable on any host via Path.win32. Internal to Clerk_backends.

val pythonpath : string list -> string

PYTHONPATH value: the given dirs joined with the OS path-list separator (';' on Windows, ':' elsewhere).

val classpath : backend:string -> string list -> string

Java -cp value: the backend output dirs (${tdir}/<backend>, then each include dir's <backend> subdir) joined with the OS path-list separator. Contains ninja variable references, for use in rule commands.

val jar_argfile_content : (string * string) list -> string

Render '-C <dir> <file>' pairs into a jar argfile body (forward-slashed, quoted) — avoids the Windows command-line length limit and backslash escaping.
