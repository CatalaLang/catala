Module Catala_utils.Path

Pure path/URL helpers. Internal: File/Message expose the host-specialised versions.

val win32 : bool Stdlib.ref

Target OS, defaulting to the host (Sys.win32). Tests override it to exercise Windows behaviour on any host; production never assigns it.

val dir_sep_re : unit -> Re.re
val list_sep : unit -> string

Separator between entries of a path-list env var (PATH, PYTHONPATH, CLASSPATH).

val clean : string -> string
val make_absolute : cwd:string -> string -> string
val remove_prefix : cwd:string -> string -> string -> string

val reverse : cwd:string -> from_dir:string -> to_dir:string -> string -> string
val url_of_absolute : string -> string

Path part of a file:// URL for an absolute OS path. Handles Windows drive paths (C:\dir -> /C:/dir) and UNC paths (\\server\share -> server/share).
